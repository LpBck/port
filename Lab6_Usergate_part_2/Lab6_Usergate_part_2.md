## Цель
 В рамках работы необходимо был развернут защищённый сетевой стенд на базе UserGate NGFW в VMware Workstation.

По заданию требовалось:
- настроить связную и защищённую сеть;
- опубликовать Web-сервер из DMZ зоны;
- настроить SSL инспектирование транзитного HTTPS трафика;
- реализовать фильтрацию контента;
- настроить систему обнаружения вторжений (IDPS);
- обеспечить доступ к Web-серверу через Web-based VPN.
## Описание  
Стенд включает сегменты:
- Trusted (внутренняя сеть);
- Untrusted (внешняя сеть);
- DMZ (демилитаризованная зона);
- Web Based VPN, RA VPN(Такой-же как в прошлой работе).

Для обеспечения безопасности были настроены:
- межсетевой экран;
- NAT публикация Web-сервера;
- SSL инспектирование HTTPS трафика;
- фильтрация категорий веб-ресурсов;
- система обнаружения вторжений (IDPS);
- Web-based VPN портал.

Для обеспечения безопасности сетевого взаимодействия были настроены правила межсетевого экрана. Разрешён доступ из Trusted зоны в Untrusted и DMZ, а также доступ через VPN туннели.  Дополнительно настроены ограничения для защиты внутренних ресурсов и DMZ.

| Default Block                              | Запретить | Любая             | Любой      | Любая             | Любой       |
## Публикация Web-сервера (DNAT)
Для публикации Web-сервера из DMZ зоны был использован механизм DNAT.  
Данный метод позволяет:  
- скрыть внутренний IP-адрес сервера;  
- обеспечить доступ к сервису через один публичный адрес;  
- централизованно контролировать и логировать входящий трафик через NGFW.
